# 地面网关 GPIO 分配说明

本文档记录 `surface_node_vscode`（矿安智联 · 地面网关）实际使用的 GPIO。
引脚定义以 `src/main.cpp` 为准，修改硬件接线或代码中的引脚后，请同步更新本文档。

| 项目   | 内容                                              |
| ---- | ----------------------------------------------- |
| MCU  | ESP32-S3 N16R8（16 MB flash + 8 MB 八线 OPI PSRAM） |
| 离线通信 | SX1278 / Ra-02，433 MHz LoRa                     |
| 显示   | 0.96 英寸 SSD1306 I2C OLED                        |
| 上报   | WiFi（2.4 GHz）→ Firebase Realtime Database REST  |
| 框架   | Arduino（PlatformIO，pioarduino 平台）               |

> 地面网关**不需要**麦克风（INMP441）和气体传感器（MQ-4/MQ-7），这两类外设都在井下节点上。

### 按系统方案逐项对照

《实验方案_离线语音与LoRa矿山安全监测》3.3 节给出的地面网关组成是
「ESP32-S3 N16R8 + Ra-02 + SH1106 OLED + 蜂鸣器 + SIM800L」；其中**蜂鸣器已删除、
SIM800L 短信已决定不做**，实际实现为 Ra-02 接收 + OLED 显示 + Wi-Fi 上云。

| 方案要求的功能               | 引脚                                               | 状态                                    |
| --------------------- | ------------------------------------------------ | ------------------------------------- |
| Ra-02（433 MHz LoRa）   | SCK12 / MOSI11 / MISO13 / NSS10 / RST14 / DIO0 9 | ✅ 已实现，与方案 3.1 节节点1 的 Ra-02 引脚**完全一致** |
| SH1106 / SSD1306 OLED | SDA5 / SCL6                                      | ✅ 已实现（12 px 中文字库与方案一致）                |
| Wi-Fi 上云（Firebase）    | 内置射频，不占 GPIO                                     | ✅ 已实现                                 |
| 蜂鸣器（三线模块）             | GPIO8                                            | ⬜ 硬件位保留（GPIO8），固件暂未驱动                      |
| 节点2 文本分片接收            | 无新增引脚                                            | ⬜ 未实现（协议侧，不占 GPIO）                    |

> 方案 3.1 节给节点1 的 OLED 写的是 `SCL18 / SDA8`。地面网关是自由接线的开发板，
> 当前实际用 `SDA5 / SCL6`，两者互不影响；若要和节点1 完全对齐，把 OLED 改接到
> `SDA8 / SCL18` 并同步改 `main.cpp` 里的两个宏即可（需要重新接线）。

## 外设接线汇总

### SSD1306 OLED（I2C，地址 `0x3C`）

| OLED 引脚 | 连接位置           |
| ------- | -------------- |
| SDA     | GPIO5          |
| SCL     | GPIO6          |
| GND     | ESP32-S3 GND   |
| VCC     | 3.3 V（以模块标注为准） |

驱动芯片按实物选择：0.96 英寸模块基本都是 SSD1306，1.3 英寸模块大多是 SH1106。
选错也能点亮，但画面会整体偏移（常见是左边少 2 列），需改 `main.cpp` 里的
`OLED_CONTROLLER`。屏不在时程序会自动跳过所有刷新，不影响 LoRa 收包。

### Ra-02 LoRa 模块（SX1278，433 MHz）

| Ra-02 编号    | 模块引脚      | 连接位置         | 用途               |
| -----------:| --------- | ------------ | ---------------- |
| 1           | GND       | GND          | 接地               |
| 2           | GND       | GND          | 接地               |
| 3           | 3.3V      | 稳定的 3.3 V 电源 | 模块供电             |
| 4           | RESET     | GPIO14       | 低电平复位            |
| 5           | DIO0      | GPIO9        | 收发完成中断           |
| 6/7/8/10/11 | DIO1~DIO5 | 暂不接          | 当前基础收发不使用        |
| 9           | GND       | GND          | 接地               |
| 12          | SCK       | GPIO12       | SPI 时钟           |
| 13          | MISO      | GPIO13       | SPI 模块到 ESP32 数据 |
| 14          | MOSI      | GPIO11       | SPI ESP32 到模块数据  |
| 15          | NSS       | GPIO10       | SPI 片选，低电平有效     |
| 16          | GND       | GND          | 接地               |

#### 供电和外围电路

- Ra-02 只能使用 **3.3 V** 供电和 3.3 V 逻辑电平，**不能接 5 V**。
- 发射时会产生较大瞬时电流，3.3 V 电源建议至少能稳定提供 300 mA，余量建议 500 mA。
- 在 Ra-02 的 3.3 V 与 GND 附近并联一个 `100 nF` 陶瓷电容和一个 `10 µF~47 µF` 电容，走线尽量短。
- 四个 GND 引脚建议全部连接到完整地平面，不要只接一个。
- **天线接口必须连接与模块频段匹配的 433 MHz 天线**。未接天线时不要进入发射状态，以免损坏射频功放。
- 实际调试中遇到过天线接触不良导致 RSSI 整体恶化约 10 dB，若发现通信距离或送达率突然变差，优先检查天线与 IPEX 座。

## 射频参数（两端必须一致）

| 参数              | 取值                                                        |
| --------------- | --------------------------------------------------------- |
| 频率              | 433 MHz                                                   |
| sync word       | `0xA3`                                                    |
| CRC             | 开启                                                        |
| 扩频因子 / 带宽 / 编码率 | 使用 arduino-LoRa 默认值（SF7 / 125 kHz / CR 4-5），**两端都不要单独修改** |

> 早期版本的地面固件（`firmware/surface_node.ino`）里写过 SF9，与井下节点不匹配，
> 那样是收不到包的。当前 `surface_node_vscode` 已不再设置扩频参数。

## 与井下节点的差异（重要）

两块板的外设和引脚**互相独立，不需要一致**，只要各自代码与自己的接线对应即可。

| 信号        | 地面网关（本工程） | 井下节点（PCB 定版） |
| --------- | --------- | ------------ |
| LoRa DIO0 | GPIO9     | GPIO21       |
| LoRa NSS  | GPIO10    | GPIO13       |
| LoRa SCK  | GPIO12    | GPIO10       |
| LoRa MISO | GPIO13    | GPIO12       |
| LoRa MOSI | GPIO11    | GPIO11       |
| LoRa RST  | GPIO14    | GPIO14       |
| OLED SDA  | GPIO5     | GPIO8        |
| OLED SCL  | GPIO6     | GPIO9        |

> 井下节点那份引脚是 PCB 打样定版方案，已无法更改；地面网关沿用这套旧引脚即可，
> 不要为了"统一"去改地面代码，否则接线也得跟着动。

## 代码位置

当前引脚宏位于 `src/main.cpp`：

```cpp
#define LORA_PIN_DIO0 9
#define LORA_PIN_NSS  10
#define LORA_PIN_MOSI 11
#define LORA_PIN_SCK  12
#define LORA_PIN_MISO 13
#define LORA_PIN_RST  14

#define OLED_PIN_SDA 5
#define OLED_PIN_SCL 6
```

串口启动横幅会打印当前生效的引脚，可以用来快速核对：

```text
  矿安智联 · 地面网关 (Surface Gateway)
  LoRa: NSS10 MOSI11 SCK12 MISO13 RST14 DIO0 9
  OLED: SDA5 SCL6
```

## 与系统方案文档的差异（需要注意）

对照《实验方案_离线语音与LoRa矿山安全监测.md》，以下几处实现与文档写法不一致：

| 项         | 方案文档写法                                  | 当前实现                |
| --------- | --------------------------------------- | ------------------- |
| 回执报文      | `ACK,<节点>,<序号>`                         | `ACK,<节点>`，不含序号字段   |
| 蜂鸣器       | 报警时鸣叫                                   | 硬件位保留（GPIO8），固件未实现        |
| 节点2 文本    | 收 `TXT,<节点>,<总片数>,<片号>,<内容>,<序号>` 并分片重组 | 未实现                 |
| 报警分级      | 按关键词判定并分级                               | 已实现（事件码 → severity） |
| OLED 中文字库 | U8g2 `u8g2_font_wqy12_t_gb2312`         | 已一致                 |

> 回执格式若要与方案对齐，需要在 `ACK` 后补一个序号字段，两端固件同时改。
